# Romanian Apartment Market Analysis

This is an **object-oriented Python data pipeline** built using **Selenium/BeautifulSoup** (for web scraping) and **Pandas/NumPy/SciPy** (for statistical analysis). It is designed for comprehensive **Romanian apartment market analysis**.

The project scrapes, filters, and analyzes real estate data to determine the best city for a rental property investment based on the estimated monthly return on investment.

---

## ✨ Key Features

* **Web Scraping:** Includes the `EstateWebScraper` class (built with Selenium and BeautifulSoup) to demonstrate the data collection process.
* **OOP Design:** Adheres to the DRY (Don't Repeat Yourself) principle by separating data calculation (`analyzer()`) from presentation (`print_console_report()`, `generate_word_report()`).
* **Data Processing:** Uses the `DataFilter` class to programmatically filter and process large raw data files (`data_raw/`) into city-specific datasets.
* **Data Cleaning:** The project uses pre-cleaned datasets (`data/`) to represent a "manually cleaned" step, ensuring the final analysis is accurate and reproducible.
* **Statistical Analysis:** The `RentalAnalyzer` class uses Pandas, NumPy, and SciPy to calculate key metrics, including mean, median, skewness, and 95% confidence intervals for property prices.
* **Automated Reporting:** Generates a formal **`.docx` report** with all findings and plots using the `python-docx` library.
* **Data Visualization:** Automatically generates and saves histograms of rental and sale prices for each city using Matplotlib.

---

## 📂 Project Structure

#### 📦 Data Folders Explained
This project contains two sets of data to show the full "before and after" pipeline:

* `/data_raw/`: Contains the two original, large CSV files (`sell_df.csv` and `rent_df.csv`) exactly as they were scraped. This is the "before" data.
* `/data/`: Contains the eight smaller, *cleaned* CSV files (`b_rent_df.csv`, `cj_sell_df.csv`, etc.). This is the "after" dataset, which has been **preprocessed to remove outliers and correct clear data entry errors identified during exploratory analysis.** **The main analysis runs from this folder.**

```text
real-estate-analysis-pipeline-python/
├── data/                    # Contains the 8 FINAL CLEANED CSV files (used by main.py)
├── data_raw/                # Contains the 2 RAW scraped CSV files (used by run_filter_demo.py)
├── src/
│   ├── __init__.py          # Makes 'src' a Python package
│   ├── analyzer.py          # RentalAnalyzer class for all calculations and plotting
│   ├── config.py            # Contains all constants and file paths
│   ├── data_filter.py       # DataFilter class for processing raw data
│   └── scraper.py           # (For Code Review) EstateWebScraper class
├── .gitignore
├── main.py                  # ===> MAIN SCRIPT: Runs final analysis from /data
├── run_filter_demo.py       # ===> DEMO SCRIPT: Runs filtering process from /data_raw
├── requirements.txt         # All project dependencies
└── README.md

# --- Folders created after running the scripts ---
#
# ├── images/                  # (Auto-generated by main.py - contains plots)
# ├── data_filtered_demo/      # (Auto-generated by run_filter_demo.py)
# └── reports/                 # (Auto-generated by main.py - contains .docx report)
```

## 🎯 Technical Focus & Architecture

This project functions as an **End-to-End Data Pipeline**, demonstrating the transition from raw unstructured web data to actionable financial insights. **The analysis is 100% reproducible** using the included raw datasets.

**Decoupled Architecture & Legacy Code:**
The system was explicitly designed to separate **Data Collection** (`src/scraper.py`) from **Data Analysis** (`src/analyzer.py`).

* **The Scraper (`src/scraper.py`):** Preserved purely as a **static code reference**. This module is intended for **code review only**, not execution, as the target website (`storia.ro`) has changed its layout.
* **The Analyzer (`main.py`):** This is the **active executable**. Because of the decoupled design, the analytical pipeline remains fully functional using the cached raw data, proving the system's resilience to external changes.

## 🚀 Getting Started

### 📋 Prerequisites
* **Python 3.9** or higher.
* **Virtual Environment** (Recommended to avoid dependency conflicts).

### 🔧 Installation
**1. Clone the repository:**
```bash
git clone https://github.com/rodel-bfr/real-estate-analysis-pipeline-python.git
cd real-estate-analysis-pipeline-python
```

**2. Create and Activate Virtual Environment:**
```bash
python -m venv venv
# Windows:
venv\Scripts\activate
# Mac/Linux:
source venv/bin/activate
```

**3. Install Dependencies:**
```bash
pip install -r requirements.txt
```

### ▶️ How to Run

**1. Run the main analysis script:**

This script runs the final analysis using the **cleaned data** from the `/data/` folder.

```bash
python main.py
```

This will print the full statistical breakdown to the console, save plots to the /images folder, and save a formal .docx report to the /reports folder.

**2. Run the Filter Demo (Optional)**

This script demonstrates the `DataFilter` class. It loads the 2 **raw** files from `/data_raw/`, filters them by city, and saves the 8 resulting (un-cleaned) files to the `/data_filtered_demo/` folder.

```bash
python run_filter_demo.py
```
